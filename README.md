# 🤖 AI Code Explainer

An AI-powered web application that explains source code in simple language using **Google Gemini AI**.

🌐 **Live Demo:** [https://YOUR-RENDER-LINK.onrender.com](https://ai-code-explainer-ht5x.onrender.com)

---

## ✨ Features

- 🚀 Explain C++, Java, Python and JavaScript code
- 📖 Beginner-friendly line-by-line explanation
- 🧠 Program summary
- ▶️ Dry run of the program
- 📤 Output prediction
- ⏱ Time Complexity
- 💾 Space Complexity
- 💡 Code improvement suggestions
- 🌙 Dark mode
- 📋 Copy explanation with one click
- 📱 Responsive UI

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/Amannn31/AI-Code-Explainer.git
```

Go into the project folder

```bash
cd AI-Code-Explainer
```

Install dependencies

```bash
npm install
```

Create a `.env` file

```env
GEMINI_API_KEY=YOUR_API_KEY
```

Start the server

```bash
node server.js
```

Open your browser

```
http://localhost:3000
```
